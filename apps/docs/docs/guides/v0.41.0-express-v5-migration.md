# Express 5.3.0 in 0.41.0

## Summary

0.41.0 moves the Express Boundary-library pin from 4.21.2 to **5.3.0**. The
Kernel HTTP shell is CORS, then Better Auth / MCP `toNodeHandler` (including
MCP DCR), then JSON. Kernel JSON applies `express.raw` on `POST /stripe/webhook`
so Billing `constructEvent` still sees a Buffer. Unnamed Express 4 wildcards
(`*`, `/*`, `params[0]`) do not match. Catch-alls that must include `/` use
brace named splats (`/{*splat}`, `/:bucket/{*key}`). The Kernel peer stays
`catalog:`. There is **no** `^4 || ^5` dual-major peer.

Express 5.3.0 does not ship TypeScript types. Keep **`@types/express` 5.0.6**.

The same Release moves Kernel telemetry to **OpenTelemetry JS SDK 2** and
Workflow Bull Board to **9.10.4**. See
[ADR-0032](https://github.com/michalkow/m5kdev/blob/main/docs/adr/0032-managed-catalog-is-express-5.md).

Standalone `body-parser` and unused `multer` leave the catalog.

There is **no** `create-m5kdev` registry transform. Catalog advancement is
`m5kdev update`. App-owned extra HTTP and pass-in Express are **Manual**.

## Who needs this migration

- **Every app on a version before 0.41.0** that uses `@m5kdev/backend`. The Managed catalog
  Express pin and Kernel peer move together.
- **Apps with extra HTTP** on a module `express` hook (or a pass-in instance)
  that still use `*`, `/*`, or `params[0]`. Those routes 404 until they are
  named brace splats.
- **Apps that apply `express.json()` before passing Express into
  `createBackendApp`.** On Express 5 that hangs Better Auth sign-in.

No action if the app never installed a pre-0.41.0 `@m5kdev/backend`.

## Prerequisites and upgrade order

Complete [Auth and Workflow boot cycle in 0.40.2](/guides/v0.40.2-auth-workflow-cycle-migration)
first if you are still on 0.40.1 Auth+Workflow.

1. Commit or stash application changes.
2. Upgrade every `@m5kdev/*` package and `create-m5kdev` together to **0.41.0**.
3. Rewrite app-owned unnamed wildcards before relying on extra HTTP in
   production.

Always invoke an exact CLI release:

```sh
pnpm dlx create-m5kdev@0.41.0 update --dry-run
```

## What changed

- Catalog `express` is `5.3.0`. Kernel peer stays `catalog:`. There is no
  `^4 || ^5` dual-major peer.
- Catalog `@types/express` is `5.0.6` (was `4.17.21`). Keep 5.0.6; Express 5
  does not bundle types.
- Catalog drops `body-parser`, `@types/body-parser`, `multer`, and
  `@types/multer`.
- Kernel shell order ([ADR-0003](https://github.com/michalkow/m5kdev/blob/main/docs/adr/0003-kernel-owns-express-http-shell.md),
  hard cut in [ADR-0032](https://github.com/michalkow/m5kdev/blob/main/docs/adr/0032-managed-catalog-is-express-5.md)):
  CORS → Better Auth `/api/auth/{*splat}` and MCP DCR / discovery
  `toNodeHandler` → JSON (`express.raw` on `POST /stripe/webhook`, else
  `express.json()`).
- Named brace splats: SPA `/{*splat}`, Auth `/api/auth/{*splat}`, MCP discovery
  `/{*splat}`, File mock `/:bucket/{*key}` via `params.key`.
- Connection start/callback query values (`redirect`, `code`, `state`, `error`,
  `error_description`) are accepted only when they are strings.
- Inbound callback and Email preview already treated query as string-only;
  route params are narrowed the same way under Express 5 types.
- Kernel `start()` waits on the HTTP `listening` / `error` events. Express 5
  also invokes a listen callback on bind failure; a success-only callback
  would swallow `EADDRINUSE`.
- OpenTelemetry JS SDK 2: `@opentelemetry/api` 1.9.1, stable packages 2.12.0,
  experimental 0.223.0, `instrumentation-express` 0.71.1. Starter still calls
  `initTelemetry({ serviceName })`.
- Workflow Bull Board `@bull-board/api` and `@bull-board/express` **9.10.4**,
  still at `/admin/queues` behind admin-role auth. `boardPath: null` still
  disables it.

The Kernel peer is `catalog:` only. Bull Board 9 depends on Express 5; the
catalog is the one physical copy.

## Migration steps

1. **Automatic** (`m5kdev update` apply, after `--dry-run`) — Upgrade catalog
   pins for `@m5kdev/*` and `create-m5kdev` to `0.41.0`. There is no AST
   transform for `0.41.0-express-v5`. Managed catalog writes `express` 5.3.0
   and `@types/express` 5.0.6, drops `body-parser` / `multer` keys, and
   advances OTEL SDK 2 and Bull Board 9.10.4. `pnpm install`.
2. **Manual** — Confirm `express` is `5.3.0` and `@types/express` is `5.0.6`.
   Remove leftover `body-parser` and `multer` catalog keys if `m5kdev update`
   did not drop them.
3. **Manual** — Rewrite app-owned extra HTTP:

   ```ts
   // before (Express 4)
   router.get("/files/*", handler);
   expressApp.get("*", spaFallback);

   // after (Express 5)
   router.get("/files/{*key}", handler);
   expressApp.get("/{*splat}", spaFallback);
   ```

   Read the splat from `params.key` / `params.splat`, not `params[0]`.
   Express 5 exposes `{*name}` as a string array of path segments — join with
   `/` before decoding.
4. **Manual** — If you pass `config.express`, remove any `express.json()` /
   `cors()` applied before `createBackendApp`. JSON-first hangs Auth on
   Express 5.
5. **Manual** — Redeploy backend (and worker if Workflow is registered).

The Kernel peer stays `catalog:`. Catalog Express 5.3.0 is the one physical
copy for Bull Board 9.

## Rollback

Revert `@m5kdev/*` and `create-m5kdev` pins to 0.40.2 and restore the Express
4.21.2 catalog pin. Named-splat routes are valid on Express 4 path-to-regexp
only after you undo them; keep the wildcard rewrite in the same revert as the
catalog pin.

## Troubleshooting

| Symptom | Cause and fix |
| --- | --- |
| Sign-in hangs on POST `/api/auth/…` | `express.json()` ran before `toNodeHandler`. Remove JSON from the pass-in instance; Kernel applies it after Auth. |
| Extra HTTP 404 | Unnamed `*` / `/*`. Name the splat (`/{*splat}`, `/:bucket/{*key}`). |
| `params[0]` is undefined | Express 5 named splat. Read `params.key` / `params.splat`. |
| Type errors on `req.params` / `req.query` | Values are `string \| string[]`. Accept only `typeof value === "string"`. |
| Missing `@types/express` | 5.3.0 does not ship types. Pin `@types/express` 5.0.6. |
| Stripe webhook signature fails | Kernel JSON must leave `POST /stripe/webhook` as a Buffer. Pass-in Express must not parse that path as JSON first. |
| Mixed `@m5kdev/*` versions | Lockstep all packages to 0.41.0. |
