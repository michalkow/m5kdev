Welcome to M5 Starter Help. Choose a topic in the sidebar to find out what you
can do and how to do it. On a phone, open the menu to see the topics.

Each guide explains the steps to follow and what to expect afterward. You can
read this help site without signing in. Use **Help** in the product to return
here whenever you need it.

## Choose your language

Use the language menu at the top of this help site to choose a supported language.
On a phone, open the menu first. Each language includes the same available guides.
You can bookmark a guide or share its address; it opens without signing in.

## If the webapp stops working

If you see **Something went wrong**, select **Reload page** to try again. If the
problem continues, contact support and describe what you were doing before the
error appeared.
