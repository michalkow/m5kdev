---
title: Run a demo job
---

1. Open **Workflows** in the web product.
2. Choose **Run demo job**.
3. Find the new run in the list and watch its status.

**Queued** means the job is waiting. **Running** means it has started.
**Completed** means it finished successfully. **Failed** means it could not
finish. If a run stays queued or fails repeatedly, contact the person who
manages your product.

This screen runs a demonstration job; it does not let you design new workflows.
